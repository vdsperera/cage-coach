## 1. Design System

### 1.1 Colour Palette Tokens

The design uses a high-contrast dark theme by default (with native `@media (prefers-color-scheme: light)` support) optimized for low-glare gym environments and high-visibility 3D contrast.

## 2. Page & View Specifications

The application operates as a single high-performance canvas view with contextual floating heads-up display (HUD) panels:

```
+-----------------------------------------------------------------------------+
| [#head] Cagecraft 3D   [Single|Spar]  [Orthodox|Southpaw]   [Tools: Ghosts, |
|                                                             Guides, Step,   |
|                                                             Split, Drill...] |
|                                                                             |
|                                                     [#card]                 |
|                                                     Jab [1]                 |
|                                                     Lead hand               |
|                                                     [== Phase Bar ==]       |
|                                                     2. Impact               |
|                                                     Arm fully straight...   |
|                                                     [Back] [Next phase]     |
|                                                     ----------------------- |
|                                                     Lead knee: 25°          |
|                                                     Elbow: 176°             |
|                                                     Hip turn: 32°           |
|                                                     ----------------------- |
|                                                     Your notes: [...]       |
|                                                     [Export notes]          |
|                                                                             |
| [#keys] Striking:     [1 Jab] [2 Cross] [3 Hook] [4 Upper] ...              |
|         Grappling:    [Q Tie] [W Double] [E Single] [R Toss] ...            |
|         Combos:       [Z 1-2] [X 1-2-3] [N Teep-Cross] ...                  |
+-----------------------------------------------------------------------------+
```

### 2.1 Fullscreen 3D Stage (`#stage`)
* **Purpose:** Hosts the WebGL rendering canvas for the octagonal cage arena, fighters, and visual annotations.
* **Canvas Styling:** `position: fixed; inset: 0; touch-action: none; display: block;`
* **Interaction:** Single-finger pointer drag or mouse drag rotates orbit azimuth and elevation; mouse wheel or pinch zooms; double-tap resets camera.

### 2.2 Top Header (`#head`)
* **Position:** Fixed top-left (`top: 14px; left: 14px; z-index: 2`).
* **Elements:**
  1. Title badge: "Cagecraft 3D" with subtitle "Technique viewer".
  2. Mode segmented button: `[Single | Sparring]` (toggles sparring partner B).
  3. Stance segmented button: `[Orthodox | Southpaw]` (mirrors coordinate space).
  4. Rig source segmented button: `[Clay | Mocap]` (mocap disabled if `clips.json` absent).

### 2.3 Floating Tools Bar (`#tools`)
* **Position:** Fixed top-right (`top: 14px; right: 14px; z-index: 2`).
* **Elements:**
  1. Visual overlay toggles: `Ghosts (G)`, `Guides (F)`, `Step (L)`, `Split (V)`, `Drill (D)`.
  2. Speed segmented selector: `[1x | 1/2x | 1/4x]`.
  3. Camera preset selector: `[Front | Side | Above | Behind | Partner's eyes]`.

### 2.4 Technique Inspector Card (`#card`)
* **Position:** Fixed top-right (`right: 14px; top: 72px; width: 300px; max-height: calc(100vh - 250px); overflow: auto`).
* **Position (Split View):** Moves to left side (`left: 14px; right: auto`) to avoid obscuring stacked right-hand viewports.
* **Position (Mobile < 760px):** Docks at bottom (`bottom: 196px; left: 14px; right: 14px; width: auto; max-height: 40vh`).
* **Internal Sections:**
  1. Technique Name & Key Badge: E.g., `Jab [1]`.
  2. Tactical Role Subheading: E.g., `Lead hand (southpaw)`.
  3. Phase Progress Bar (`#phases`): Segmented fr-grid with real-time white cursor tick.
  4. Phase Title & Explanation: E.g., `2. Impact — Arm fully straight, chin tucked...`.
  5. Stepping Buttons (`#stepBtns`): `[Back (Backspace)]` and `[Next phase (Enter)]`.
  6. Biomechanical Readouts Grid (`#readouts`): 2-column tabular readout list.
  7. Tactical Coaching Cues (`#cues`): Bulleted list of form reminders.
  8. User Notes & Export (`#notes`, `#notesRow`): Autosaving textarea with "Export all notes" button.

### 2.5 Quick Hotkey Dock (`#keys`)
* **Position:** Fixed bottom (`left: 14px; right: 14px; bottom: 14px; z-index: 2`).
* **Layout:** 3 horizontal scrollable rows (`Striking`, `Grappling`, `Combinations`).
* **Tile Component:** Fixed-width interactive tile displaying shortcut badge (`<kbd>`), title, and tactical role.

### 2.6 Drill Coach Banner & Overlay (`#drill`, `#callout`)
* **Drill Controls (`#drill`):** Centered floating bar below header with pool selector (`Striking`, `Grappling`, `Combos`, `All`), gap selector (`3s`, `5s`, `8s`), and audio toggles (`Voice`, `Tick`).
* **Drill Callout Overlay (`#callout`):** Centered screen overlay with oversized gold typography (`font: 700 clamp(40px, 8vw, 96px)`), announcing the requested technique and hotkey during reaction windows.

## 3. Component Specifications

### 3.1 Segmented Button Control (`.seg button`)
* **Purpose:** Mutually exclusive or toggle state controls in header and toolbars.
* **States:**
  - *Default:* Transparent background, `--ink-2` text color.
  - *Hover:* Background `rgba(255,255,255,0.06)`, text `--ink`.
  - *Focus:* 2px solid `--blue` outline with 2px offset (`:focus-visible`).
  - *Active / Pressed (`aria-pressed="true"`):* Background `--key`, text `--ink`.
  - *Disabled:* Opacity 0.45, cursor default.
* **Accessibility:** Native `<button>` elements with `aria-pressed="true|false"` and embedded `<kbd>` indicators.

### 3.2 Technique Tile (`.key`)
* **Purpose:** Fast technique switching tile inside the bottom dock.
* **Props:** `key` (character), `name` (string), `side` (string), `group` (string), `isActive` (boolean).
* **States:**
  - *Default:* Background `--panel`, border 1px solid `--line`, text `--ink`.
  - *Hover:* Border-color `--ink-2`.
  - *Focus:* 2px outline `--blue`.
  - *Selected (`.key.on`):* Border-color `--red`, `<kbd>` background `--key-on`, text `#fff`.
* **Interaction:** Click or keypress selects technique, triggers `setTech(index)`, resets playback to `t = 0`, and repopulates card readouts.

### 3.3 Biomechanical Readout Grid (`#readouts`)
* **Purpose:** Displays live angular telemetry in tabular format.
* **Structure:** 2-column grid (`grid-template-columns: 1fr 1fr; gap: 4px 12px`).
* **Row Items:**
  - Lead knee bend: `<b>25°</b>`
  - Rear knee bend: `<b>30°</b>`
  - Lead elbow: `<b>176°</b>`
  - Rear elbow: `<b>45°</b>`
  - Hip turn: `<b>32°</b>`
  - Torso lean: `<b>12° fwd</b>`
  - Head height: `<b>1.68 m</b>`
  - Hand height: `<b>1.42 m</b>`
* **Accessibility:** Wrapped in semantic pairs with tabular numerical fonts (`font-variant-numeric: tabular-nums`).

## 4. User Flow Maps

### Flow 1: 3D Technique Inspection & Phase Stepping (US-001, US-003)
```
[User loads app / clicks technique tile (e.g. '2' Cross)]
   │
   ▼
[Fighter A loads at stance t=0; card shows 'Cross (Rear hand)']
   │
   ├── User drags canvas ──► Orbital camera smoothly rotates around fighter
   │
   ├── User presses Space ──► Animation plays/pauses at current progress
   │
   ├── User clicks 'Next phase' / Enter ──► Timeline advances to Impact (t=0.5)
   │                                        Card displays: "Arm straight, chin tucked"
   │                                        Readouts update: Elbow 178°, Hip turn 42°
   │
   └── User clicks 'Back' / Backspace ──► Timeline steps back to Drive (t=0.38)
```

### Flow 2: Stance Mirroring & Telemetry Comparison (US-002, US-004)
```
[User views technique in standard Orthodox stance]
   │
   ▼
[User presses 'A' or clicks 'Southpaw' button]
   │
   ├── Engine executes mirrorPose(pose): inverts X translation and Y/Z rotations
   │
   ├── Visual mesh instantly reflects left-handed fighter (right hand lead)
   │
   └── Readouts instantly re-route lead tracking to right knee and right elbow
```

### Flow 3: Interactive Drill Training Session (US-005)
```
[User clicks 'Drill' button or presses 'D']
   │
   ▼
[Drill bar appears at top; state = 'wait'; pool = Striking; gap = 5s]
   │
   ├── Wait timer expires (performance.now() >= drill.at)
   │      │
   │      ▼
   │   [Callout phase: 880Hz audio beep sounds + voice speaks 'Lead hook']
   │   [Screen displays large banner: 'Lead hook [3]']
   │   [User executes physical punch during 2.75s reaction window]
   │
   ├── Reaction window expires
   │      │
   │      ▼
   │   [Perform phase: 440Hz tone sounds + banner clears]
   │   [3D model performs Lead Hook in slow motion, showing correct hip pivot]
   │   [Model pauses at peak extension for 300ms]
   │
   └── Cycle loops back to 'wait' for next random callout
```

### Flow 4: Personal Notes Capture & JSON Export (US-009)
```
[User selects technique (e.g. 'W' Double Leg)]
   │
   ▼
[User types note into textarea: "Keep head tight to ribs, drive off back foot"]
   │
   ├── 400ms debounce timer triggers saveNotes()
   │      │
   │      ▼
   │   [Text validated (<10k chars) and written to localStorage['cagecraft3d-notes']]
   │   [Status indicator displays 'Saved']
   │
   └── User clicks 'Export all notes'
          │
          ▼
       [Blob created with JSON payload of all stored technique notes]
       [Browser downloads 'cagecraft-notes.json' to user's device]
```

## 5. Navigation & Keyboard Command Matrix

| Hotkey | Category | Action | Target State / Component |
| :--- | :--- | :--- | :--- |
| `1` – `0` | Techniques | Select Striking (Jab, Cross, Hook, Upper, Elbow, Knee, Teep, Roundhouse, Slip, Check) | `state.tech = index`, `#keys` tile selected |
| `Q` – `P` | Techniques | Select Grappling (Tie, Double, Single, Toss, Sprawl, Mount, Guard, Side, RNC, Armbar) | `state.tech = index`, partner visible |
| `Z, X, N, H, J, K` | Techniques | Select Combo (1-2, 1-2-3, Teep-Cross, Clinch-Knee, Double-Mount, Cross-Hook-Knee) | `state.tech = index`, combo progress active |
| `Space` | Playback | Play / Pause animation toggle | `state.playing = !state.playing` |
| `[` / `]` | Playback | Step backward / forward 15ms frame | `state.t = (state.t ± 0.015)` |
| `Enter` | Stepping | Advance to next phase milestone | `nextPhase()`, `#phaseName` updates |
| `Backspace` | Stepping | Return to previous phase milestone | `prevPhase()`, `#phaseName` updates |
| `Tab` | Staging | Toggle Single vs. Sparring Partner view | `state.mode = 'single' | 'spar'` |
| `A` | Stance | Toggle Orthodox vs. Southpaw stance | `state.southpaw = !state.southpaw` |
| `M` | Source | Toggle Procedural Clay vs. Motion Capture | `state.src = 'clay' | 'mocap'` |
| `G` | Overlays | Toggle Keyframe Ghost Clones | `state.ghosts = !state.ghosts` |
| `F` | Overlays | Toggle Trajectory Guides, Footprints, Arcs | `state.guides = !state.guides` |
| `L` | Playback | Toggle Auto-Pause at Phase Milestones | `state.step = !state.step` |
| `V` | Viewport | Toggle Quad-Split Scissor Mode | `state.split = !state.split`, `.split` body |
| `D` | Training | Toggle Interactive Drill Coach | `state.drill = !state.drill`, `#drill` / `#callout` |
| `S` | Speed | Cycle playback speed (1x → 0.5x → 0.25x) | `state.speed = 1 | 0.5 | 0.25` |
| `C` | Camera | Cycle camera preset (Front, Side, Above, Behind, Partner) | `state.cam = (state.cam + 1) % 5` |
| `Arrow Keys` | Camera | Orbit camera azimuth and elevation | Adjusts `camGoal.theta` and `camGoal.phi` |
